## 진행 상황 — 2026-11-04

### 1. 공개 데이터 분석

- 사용 데이터: WebQAmGaze
- 원본 출처: https://github.com/tfnribeiro/WebQAmGaze
- 데이터 위치: `scripts/pre_processed_data/`
- 데이터 형식: 참가자별 JSON
- 분석 환경: Google Colab / Python

### 2. 완료한 작업

- WebQAmGaze 참가자 JSON 파일 로딩 성공
- `nr`(일반 읽기), `is`(정보 탐색) 과제 구분 확인
- 실제 시선 X 좌표의 시간 그래프 생성
- 초당 가로·세로 시선 이동량 계산
- 참가자 3명, 총 30개 과제의 이동량 비교
- 화면 해상도를 이용한 이동량 정규화
- 영어 참가자 파일 12개에서 NR 5개, IS 5개씩 과제 라벨 확인
- 12개 파일 중 11개가 측정 빈도 10Hz 이상임을 확인

### 3. 주요 관찰

- 첫 참가자의 평균 가로 이동량은 NR 490.71px/s, IS 559.29px/s로 나타남.
- 참가자 2는 이동량이 크게 나타났으며, 시선 검증 지표의 품질을 추가로 확인해야 함.
- 참가자 3은 측정 빈도가 8.125Hz로 10Hz 기준 미달.
- 10Hz 기준 충족은 최종 학습 데이터 품질 통과를 의미하지 않음.

### 4. 사용한 특징

- `horizontal_travel_per_s`: 가로 좌표 변화량의 절댓값 합계를 유효한 측정 시간으로 나눈 값
- `vertical_travel_per_s`: 세로 좌표 변화량의 절댓값 합계를 유효한 측정 시간으로 나눈 값
- 연속 측정점의 시간 차이가 0ms 초과, 200ms 이하인 구간만 계산
- 참가자 간 비교를 위해 화면 너비·높이로 나눈 정규화 값도 계산

### 5. 현재 한계

- 일부 참가자 자료의 시선 측정 품질이 낮을 가능성이 있음.
- 실제 글 영역의 크기 차이는 아직 보정하지 못함.
- 측정값의 단위·시간·품질 기준은 추가 검증 필요.
- 참가자 분리 AI 학습 및 성능 평가는 아직 수행하지 않음.
- 실제 웹캠 입력에 대한 모델 적용은 검증하지 않았으며, 기본적으로 비활성 상태임.
